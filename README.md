# unbake-proto

Decompile baked protobuf descriptors into human-readable `.proto`  
`unbake-proto` can work for all cases baked by `FileDescriptorSetSchema`

## usage

```shell
bun i
bun run unbake <input>
bun run unbake <input> > [output]
```

## requirements

- Bun for the runtime; others can be used instead
